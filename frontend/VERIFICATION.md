# Проверки — 24 сентября 2026

## Успешные команды

- `npm run build`: TypeScript + Vite, 39 модулей, production bundle создан.
- `npm run typecheck`: без ошибок.
- `npm run lint`: без ошибок.
- `npm test`: 14 тестов успешно.

Unit-тесты проверяют персонализацию, AND/OR, все общие и специальные поля, ограничения регионов для онлайн, окно 7 дней, неизвестные булевы значения, диапазоны дат/чисел, очистку несовместимых фильтров, уникальность городов, 4 события на тип, сохранение и повреждение профиля. В ходе проверки исправлено принятие унаследованных ключей объекта вместо допустимого типа события.

## Встроенный браузер

- Пройден новый профиль в production-сборке на `http://127.0.0.1:4173`: приветствие → 9 класс → Москва → Олимпиады → свободный текст → лента.
- «Далее» недоступна до выбора класса. Возврат с города сохраняет выбранный класс.
- Поиск несуществующего города показывает пустой результат.
- Завершённый онбординг пропускается после перезагрузки.
- Редактирование профиля сохраняет класс и свободный текст после перезагрузки.
- Начальная подборка для 9 класса / Москвы / олимпиад — 2 события.
- Отмена сброса в bottom sheet сохраняет предыдущую выдачу; фокус возвращается на «Все фильтры».
- Применённый сброс даёт 16 событий, «Бесплатно» — 8.
- Перевёрнутый диапазон команды 3–2 блокирует применение; 3–3 оставляет один хакатон; смена типа на карьеру даёт четыре записи.
- Подробности открываются; отображается пояснение об отсутствии реальной заявки.
- Режимы ошибки, повторной попытки и пустой выдачи проверены.

- Визуально осмотрены приветствие, класс, лента и bottom sheet; отдельно просмотрены фреймы Figma 1–5 и секция состояний. Точное пиксельное соответствие не подтверждено.
- В чистой production-вкладке после основного сценария, фильтров, подробностей и перезагрузки консоль не содержит ошибок.

## Ограничения

`npm run test:e2e` не завершился: браузер Playwright отсутствовал; загрузка Chromium была прервана после сетевой ошибки/медленной загрузки. Попытка запуска установленного Chrome завершилась SIGABRT до выполнения тестов в ограниченном окружении. Поэтому автоматические E2E не заявлены как пройденные; сценарий сохранён для запуска локально/в CI. Интерактивная проверка выше выполнена через встроенный браузер.

Во время форматирования исходников горячее обновление Vite временно выдало ошибку загрузки модуля/invalid hook call. После полной загрузки и в отдельной production-вкладке проблема не воспроизводится.

Не проверялись реальные устройства, экранная клавиатура iOS/Android, screen reader и клиент MAX. Safe area, dvh и прокрутка предусмотрены стилями, но требуют проверки внутри MAX.

Figma MCP сообщает исчерпание лимита. Поэтому оригинальные графические ассеты, точный шрифт и экспорт design-context не получены. Оформление онбординга — приближение на основании браузерного просмотра и задания. Лента/профиль/подробности/фильтры созданы самостоятельно.
